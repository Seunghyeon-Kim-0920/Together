## Data safety 입력 전 검토할 항목

- "앱이 데이터를 수집하거나 공유합니까?"에는 **예**를 검토합니다. 선택형 공동 여행과 ML Kit 진단 정보 때문에 전체 앱을 "수집 없음"으로 신고하면 부정확합니다.
- 선택형 공동 여행에 대해 **이름**, **사용자 ID**, **구매 내역/지출 정보**, **기타 금융 정보(분담액·결제자)**를 해당 Play Console 분류에 맞춰 검토합니다. 목적은 앱 기능, 수집은 기능 이용 시 선택적입니다. 서버로 보내는 데이터는 전송 중 암호화(HTTPS/TLS)를 사용합니다.
- Firebase Auth 및 ML Kit가 처리하는 **기기 또는 기타 ID**, **진단 정보**, 필요하면 **앱 상호작용/성능**을 SDK 공식 공개자료와 대조하여 신고합니다. Google이 서비스 제공자로 처리하는 항목을 Play의 "공유"로 어떻게 답할지는 공식 예외 기준에 따라 결정합니다.
- 로컬에서만 읽는 알림 원문·개인 가계부·명세서 본문을 서버 수집으로 잘못 신고하지 않습니다. 단, 별도 사용자 파일 공유는 사용자가 선택한 대상 앱으로 전달된다는 사실을 정책에 공개합니다.
- 광고 없음, 개인 가계부 판매 없음, 개인 가계부 이용에 로그인 불필요. 공동 여행은 익명 인증을 생성하므로 **계정 삭제 URL**과 앱 안의 삭제 요청 경로를 모두 신고합니다.
- 삭제 요청은 이메일 접수 방식입니다. 계정과 연관 공동 여행 데이터를 찾아 처리하는 운영자의 실제 대응 절차가 필요합니다. 앱 안의 버튼은 요청 메일을 열 뿐 **즉시 삭제를 완료하지 않습니다**.
- Play Console의 개인정보처리방침 URL, 계정 삭제 URL, Data safety 답변과 앱 내 방침 내용이 일치하는지 검토합니다. 계정이 아직 Play Console에 없거나 권한이 없으면 제출 여부를 미확인으로 남깁니다.
