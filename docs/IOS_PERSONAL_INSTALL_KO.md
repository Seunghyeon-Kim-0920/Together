# 맥북에서 내 아이폰에 지갑의 일기 설치하기

이 문서는 앱스토어 출시 없이 **본인의 맥북과 아이폰에** 개발용 앱을 직접 설치하는 방법입니다. Apple의 무료 Personal Team을 이용합니다. iOS 프로젝트와 아래 절차는 Windows에서 준비했으며, 실제 Mac 빌드 및 iPhone 설치·동작은 아직 검증되지 않았습니다. 오류가 발생할 수 있습니다.

## 먼저 알아둘 점

- 무료 계정의 개발용 앱은 프로비저닝 프로필이 발급 후 7일에 만료되어 다시 빌드하고 설치해야 합니다. 이 방법은 앱스토어에 앱을 게시하지 않습니다.
- 앱을 삭제하거나 번들 식별자(Bundle Identifier)를 바꾸면 기기에 저장된 가계부에 접근하지 못하거나 데이터가 삭제될 수 있습니다. 업데이트·재설치 전에 기기 전체 백업과 앱에서 가능한 가계부 내보내기를 확인하세요. 기기에 처음 설치한 이후에는 같은 Apple 계정과 같은 번들 식별자를 유지하고, 앱을 지우지 않은 채 Xcode에서 다시 실행하세요. 백업·재설치 복원이 모든 상황에서 보장되지는 않습니다.
- 이 프로젝트의 카드·문자·이체 알림 자동기록 및 한도 알림은 **Android 전용**입니다. iPhone에서는 지원하지 않습니다. 이미지 및 스캔 문서 OCR도 Android 전용입니다.
- iPhone에서 수동 지출 추가·저장·앱 재실행, PDF 저장/공유·가져오기, 여행 초대·동기화는 아직 실기기에서 검증되지 않았습니다. 특히 iOS PDF 저장 버튼의 성공 표시는 파일이 실제 저장됐다는 보장이 아닙니다. 중요한 내용은 파일 앱에서 직접 열어 확인하세요.
- 아래 명령은 처음 내려받는 경우입니다. 이미 지갑의 일기를 개발 중이라면 기존 폴더나 변경사항을 덮어쓰지 말고 별도의 새 폴더에서 시작하세요.

## 준비물

1. Xcode 26 이상을 설치할 수 있는 호환 macOS 맥북과 iOS 15 이상 아이폰, 두 기기를 연결할 케이블, 인터넷. Xcode의 지원 macOS 버전은 App Store에서 확인하세요.
2. Mac App Store에서 Xcode 설치 후 처음 열어 필수 구성요소 설치와 약관 화면을 완료하세요.
3. Node.js 22.13 이상과 npm. 터미널에서 `node --version`과 `npm --version`으로 확인하세요. Node는 공식 사이트 <https://nodejs.org/>에서 설치할 수 있습니다.
4. 아이폰 소유자의 Apple 계정. 계정 비밀번호, 인증 코드, 서명 파일을 다른 사람이나 채팅에 보내지 마세요. Apple이 개발자 등록 및 약관 동의를 요청하면 기기 소유자가 직접 진행하세요.

## GitHub에서 준비

맥북에서 터미널을 열어 아래 명령을 한 줄씩 실행합니다. 처음 명령은 현재 위치에 `Together` 폴더를 만듭니다.

```bash
git clone --branch codex/wallet-diary-v1 https://github.com/Seunghyeon-Kim-0920/Together.git
cd Together
npm ci
npm run ios:sync
npx cap open ios
```

`npm run ios:sync`는 웹 화면을 빌드하고 iOS 프로젝트에 복사합니다. 이 단계는 반드시 **맥에서** 실행하세요. GitHub에는 생성된 웹 자산이 들어 있지 않아, 동기화하지 않고 Xcode만 열면 앱이 빌드되지 않거나 제대로 실행되지 않을 수 있습니다. 첫 빌드에는 Swift 패키지 다운로드도 필요합니다. 에러가 나오면 임의로 유료 서비스에 가입하지 말고 오류 문구를 확인하세요.

## 아이폰에 설치

1. 아이폰을 맥북에 연결하고 잠금을 푼 다음, 두 기기에서 신뢰 여부를 묻는 화면이 나오면 확인합니다.
2. Xcode 메뉴 **Settings → Accounts**에서 아이폰 소유자의 Apple 계정으로 로그인합니다. 무료 계정은 `Personal Team`으로 표시됩니다.
3. Xcode 왼쪽에서 `App` 프로젝트 → `App` 타깃 → **Signing & Capabilities**를 엽니다. `Automatically manage signing`을 켜고 본인의 Personal Team을 선택합니다.
4. 번들 식별자 등록 충돌이 나면 Xcode의 Bundle Identifier를 본인만 쓰는 고유한 값으로 바꿉니다. 예를 들면 `com.example.walletdiary`가 아니라 본인에게 고유한 영문 식별자를 사용하세요. 실제 충돌 여부는 계정마다 다릅니다. 최초 설치 후 이 값을 바꾸면 별도 앱으로 취급될 수 있으니 계속 유지하세요.
5. Xcode 상단 실행 대상을 연결한 아이폰으로 선택합니다. 아이폰에서 개발자 모드가 필요하다고 안내하면 **설정 → 개인정보 보호 및 보안 → 개발자 모드**를 켜고, 재시동 후 아이폰에서 직접 확인합니다. 개발자 모드는 기기 보안을 낮추므로 직접 이해하고 동의할 때만 켭니다.
6. Xcode의 ▶ 실행 버튼을 눌러 빌드하고 설치합니다. 아이폰에서 개발자 앱 신뢰를 요청하면 화면의 안내에 따라 확인합니다.

## 최초 설치 후 확인할 것

실제 재무 자료를 넣기 전에 가상 금액으로만 시험하세요.

1. 앱을 열고 생활 가계부에 지출을 하나 입력합니다. 앱을 완전히 닫았다 다시 열어 날짜·금액·사용처가 남는지 확인합니다.
2. 여행 가계부를 만들고 참가자·지출·정산을 확인합니다. 본인과 초대한 상대가 함께 쓸 계획이면 두 기기에서 초대, 재접속, 동기화와 정산 결과를 별도로 확인합니다. 초대 코드와 개인 금융정보는 공개 채팅에 올리지 마세요.
3. PDF를 저장하거나 공유했다면 파일 앱 또는 받은 쪽에서 파일을 직접 열어 확인합니다. 저장 성공 표시만으로 저장을 가정하지 마세요.
4. 시험 도중 앱이 열리지 않거나 데이터가 사라지면 실제 가계부를 입력하지 말고 Xcode 오류 메시지나 개인정보를 가린 화면을 기록합니다.

## 7일 후 다시 설치

프로필이 만료되면 같은 맥북, 같은 Apple 계정, 같은 프로젝트와 번들 식별자로 아이폰을 연결해 Xcode에서 다시 ▶ 실행합니다. 소스가 변경되지 않았다면 일반적으로 다시 내려받을 필요는 없습니다. 앱을 삭제하지 마세요. 재설치 전 백업을 확인하세요.
