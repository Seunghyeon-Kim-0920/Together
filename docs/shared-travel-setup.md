# 선택형 공동 여행 연결 (무료 Spark 전용)

현재 `src/lib/sharedTravelConfig.ts`는 사용자 소유 **wallet diary** 프로젝트
`wallet-diary-c2a1a`에 연결되어 있습니다(2026-09-20 확인).
컴퓨터의 `Together` 폴더명과 무관하며, 기존 여행 웹사이트 프로젝트는 변경하지 않았습니다.

- 무료 Spark 유지, 결제 계정 연결/요금제 업그레이드 없음.
- 기본 Firestore Standard 데이터베이스: 사용자가 선택한 서울 `asia-northeast3`.
- 익명 인증만 사용 설정, 익명 계정 자동 정리 꺼짐.
- Web 앱 `Wallet Diary Shared Travel`: `1:609381247951:web:6355e8d3ed31588a1540ba`.
- `firebase.rules`를 콘솔에 게시했습니다. 전체 공개 테스트 모드는 사용하지 않았습니다.
- Analytics/Functions/Storage/전화번호 인증 SDK는 앱에 추가하지 않았습니다.
- 사용자가 공동 여행에 동의한 뒤에만 익명 인증 및 통신을 시작합니다.
- 실제 서버와 분리된 브라우저 두 개로 초대·참여·지출·오프라인/재연결·익명 ID 유지·시험 데이터 삭제를 검증했습니다. 두 실제 휴대폰의 검사와는 다릅니다.

공개 설정은 관리 권한 비밀키가 아닙니다. 앱의 권한은 서버 보안 규칙으로 제한합니다.
개인 가계부와 PDF/파일 공유는 Firebase 연결 없이도 계속 사용할 수 있습니다.

## 프로젝트를 새로 연결하는 경우

1. 본인 Google 계정으로 Firebase 콘솔에서 프로젝트를 만듭니다. **Spark 요금을 유지**하고 결제 계정은 연결하지 않습니다. Analytics, Cloud Functions, Cloud Storage, 전화번호 인증은 이 기능에 필요하지 않습니다.
2. Authentication에서 Anonymous(익명) 제공자만 활성화합니다. 익명 계정 자동 정리는 켜지 않습니다(오래된 여행의 접근을 잃을 수 있습니다).
3. 기본 Cloud Firestore Standard 데이터베이스를 생성하고 처리 지역을 확인합니다. 테스트 모드의 전체 허용 규칙을 배포하지 않습니다.
4. 이 저장소의 `firebase.rules`를 에뮬레이터로 다시 검증한 뒤 **선택한 프로젝트에만** 배포합니다. 프로젝트 선택을 확인하지 않은 배포는 금지합니다.
5. Web 앱 등록 후 공개 설정 `apiKey`, `projectId`, `appId`, `authDomain`만 `sharedTravelConfig.ts`에 넣고 다시 빌드합니다. 서비스 계정 키·비밀번호는 소스나 채팅에 넣지 않습니다.
6. 실제 Android 두 대로 초대→참여→각자 지출→오프라인→재접속→동시 수정→탈퇴→관리자 삭제를 검사합니다. Play 공개 배포 전에 실제 프로젝트 권한, App Check/남용 방어 구성 가능 여부, 익명 계정 삭제 절차, 공개 개인정보처리방침 및 Data safety 신고를 검토해야 합니다.

## 동작과 제한

- 생활 가계부/알림 원문/신뢰 앱/계좌·잔액/개인 카테고리 학습을 업로드하지 않습니다.
- 사용자가 동의한 여행의 현재·이후 지출만 동기화합니다. 자동기록 지출은 개인 기록에 남고, 사용자가 여행으로 옮기며 결제자·분담자를 확인해야 공유됩니다.
- 앱에서 해당 여행을 열고 인터넷이 연결되어 있을 때 동기화합니다. 백그라운드 실시간 전송을 보장하지 않습니다.
- 공유 전 참가자·화폐를 정합니다. 연결 후에는 이름·참가자·화폐 변경을 막습니다. 공유 정산은 최대 20명, 앱의 지출 문서는 여행당 5,000개까지 읽습니다(삭제 표식 포함). 기기 로컬 여행의 기존 한도는 별도입니다.
- 무료 한도는 **프로젝트 전체**에 적용됩니다. 무제한 사용자를 지원하는 무료 서버가 아닙니다. 한도·네트워크 오류 시 기기의 전송 대기를 보존하며 자동 유료 전환은 하지 않습니다. 읽기·쓰기 일일 한도와 저장/전송량 한도의 회복 시점은 다릅니다.
- 지출은 작성자와 관리자만 변경합니다. 수정은 서버 버전을 확인하며 충돌은 사용자 선택을 기다립니다. 여러 사람의 동일 금액 지출을 중복으로 합치지 않습니다.
- 초대는 256비트 임의 코드, 24시간 만료입니다. 코드를 가진 사람은 참여할 수 있습니다. 동행에게만 전달하고 필요하면 취소하세요.
- 익명 연결은 앱 삭제/데이터 초기화/기기 변경 시 복구되지 않을 수 있습니다. 이전 기기의 접근은 관리자가 해제하고 새 기기를 초대해야 합니다. Google 계정 복구 기능은 구현되지 않았습니다.
- 관리자 서버 삭제는 데이터 접근을 먼저 막고 하위 문서를 삭제합니다. 실패하면 재시도해야 합니다. 이미 내려받은 타인의 사본은 삭제할 수 없습니다. 참여 종료만으로 기존 정산 지출이 없어지지는 않습니다.

## 개발 검증

`npm test`, `npm run typecheck`, `npm run lint` 후,
JDK 21 경로를 설정한 터미널에서 `npm run test:shared:emulator`를 실행합니다.
Windows의 한국어 Java 환경에서 에뮬레이터 오류 메시지 리소스가 없을 경우
해당 터미널에만 `JAVA_TOOL_OPTIONS=-Duser.language=en -Duser.country=US`를 설정합니다.
에뮬레이터는 `demo-wallet-diary` 프로젝트와 127.0.0.1만 사용합니다.

공식 자료: [Firebase 요금](https://firebase.google.com/pricing),
[Firestore 오프라인 동작](https://firebase.google.com/docs/firestore/manage-data/enable-offline),
[보안 규칙](https://firebase.google.com/docs/firestore/security/rules-conditions).
