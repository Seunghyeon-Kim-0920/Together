## 설정과 확인

받은 PDF를 휴대폰에 저장한 뒤 상단 가져오기에서 선택하세요. 앱 원본 PDF는 여행 합치기 화면이 열립니다. 외부 은행 파일은 내용을 확인한 뒤 일반 가계부 또는 여행에 등록하세요. 화폐를 임의로 환산하지 않습니다.

모든 임의 파일·은행 서식·암호화 문서를 인식하는 것은 아닙니다. 이미지·스캔 결과는 원본과 확인하세요. 기기 내 문자 인식은 라틴·한국어·중국어·일본어·데바나가리를 지원합니다. 읽기 제한은 40 MB/외부 PDF 100페이지/20,000행이며 가계부 저장은 5,000건입니다. 저장 지출과 일치하지 않거나 여러 후보가 있는 환불·취소는 자동 변경하지 않고 검토에서 제외합니다.

국가·패키지 목록으로 은행을 제한하지 않지만 모든 은행·언어·알림 형식의 인식을 보장하지 않습니다. 삭제된 알림은 복원할 수 없고, 알림이 전혀 없는 거래는 읽지 않습니다. 실계좌 자동 동기화는 공식 Open Banking 공급자·백엔드·은행 인증 및 동의 연결이 아직 필요합니다. 은행 앱의 비공개 화면이나 저장소를 읽지 않습니다.

## 설치와 보관

기존 앱과 같은 서명 키를 사용합니다. 앱을 삭제하지 말고 APK를 열어 업데이트하세요. 중요한 가계부는 업데이트 전에 PDF로 백업하세요. 실제 카카오톡·WhatsApp 수신 및 모든 갤럭시 모델에서 실기기 검증을 완료한 것은 아닙니다. AAB 서명이 Play Console 심사 승인을 의미하지는 않습니다.

지원 범위는 Android 7 이상(API 24~)이며 Android 16도 대상입니다. 모든 기종·OS 버전에서 실기기 검증을 마친 것은 아닙니다. 알림 접근 권한과 OS 감지 서비스 연결은 별개이며, 실제 연결이 끊겼다면 요약과 자동기록 설정에 표시합니다. 사용자 기기의 Android 16 / 기존 앱 1.5.0 문제는 실제 휴대폰 연결 후 최종 재확인이 필요합니다.

SHA-256 파일 해시는 `SHA256SUMS.txt`에 있습니다. `wallet-diary-upload.jks`, `signing.properties`, `SIGNING-CREDENTIALS.txt`는 민감한 서명 자료라 Git에 포함되지 않습니다. 안전한 별도 위치에 백업하세요.

서명된 IPA 생성에는 macOS/Xcode와 Apple Developer 배포 인증서·프로비저닝 프로파일이 필요합니다.
