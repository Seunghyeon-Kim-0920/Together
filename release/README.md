# 지갑의 일기 v1.4.0

- `Wallet-Diary-v1.4.0.apk`: Android 기기에 직접 설치하는 서명 APK
- `Wallet-Diary-v1.4.0.aab`: Google Play Console 제출용 서명 Android App Bundle
- 패키지 ID: `com.seunghyeonkim.walletdiary`
- 버전: `1.4.0` (version code 106)
- 최소 Android: 7.0 / API 24, target/compile SDK: 36

## 이번 업데이트

- 생활 지출을 여행 가계부로 이동하며 날짜·금액·화폐를 보존하고 결제자·분담 참가자를 선택합니다.
- 여행 전체 `.walletdiary` 파일을 공유하고, 받은 파일의 참가자·추가/중복/충돌 건수·통화별 금액·정산을 확인한 뒤 기존 여행에 합칩니다.
- 같은 파일 재가져오기와 여행으로 이동한 원본의 재가져오기 중복을 방지합니다. 기존 편집값은 보존합니다.
- 완료된 보낸 계좌이체·실제 출금된 자동이체·정기이체 알림 인식을 추가했습니다. 받은 이체·잔액·예정/실패·명시된 본인 계좌 간 이체는 제외합니다.
- 여행으로 옮긴 결제의 취소는 여행 확인 경로를 안내하며 정산을 추측으로 자동 변경하지 않습니다.

## 사용 방법

생활 지출 아래 `여행 가계부로 옮기기`를 누릅니다. 동행 내역은 여행의 `가계부 파일 보내기`로 전달하고, 수신자는 파일을 기기에 저장한 뒤 `동행 내역 가져오기`에서 선택합니다. PDF와 요약 공유는 읽기용이고, 합치기에는 원본 `.walletdiary` 파일이 필요합니다. 파일 첨부를 지원하는 전송 앱을 사용하세요.

알림 기록은 `일반 가계부 → 알림 기반 결제·이체 자동기록 → Android 알림 접근 허용`에서 설정합니다. 새 앱은 은행·카드사의 공식 앱임을 확인하고 신뢰 대상으로 등록한 뒤 지원되는 고신뢰 알림부터 자동 기록됩니다. 알림 형식에 따라 일부 거래가 누락될 수 있습니다.

## 아직 연결되지 않은 기능

알림이 전혀 없는 거래의 실계좌 동기화는 v1.4.0에서 작동하지 않습니다. 공식 Open Banking 공급자 계정·보안 백엔드·은행 인증과 동의 연결이 필요합니다. 다른 은행 앱의 비공개 화면/저장소를 읽지 않고 공급자 비밀키를 APK에 포함하지 않습니다. 모든 국가·은행 지원을 보장하지 않습니다.

## 설치와 보관

기존 앱과 같은 서명 키를 사용합니다. 앱을 삭제하지 말고 APK를 열어 업데이트하세요. 중요한 가계부는 업데이트 전에 파일로 백업하세요. 모든 갤럭시 모델 및 실제 메신저별 수신 동작을 실기기에서 검증한 것은 아닙니다.

SHA-256 파일 해시는 `SHA256SUMS.txt`에 있습니다. `wallet-diary-upload.jks`, `signing.properties`, `SIGNING-CREDENTIALS.txt`는 민감한 서명 자료라 Git에 포함되지 않습니다. 안전한 별도 위치에 백업하세요.

서명된 IPA 생성에는 macOS/Xcode와 Apple Developer 배포 인증서·프로비저닝 프로파일이 필요합니다.
