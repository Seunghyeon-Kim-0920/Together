# 지갑의 일기 v1.5.0

- `Wallet-Diary-v1.5.0.apk`: Android 기기에 직접 설치하는 서명 APK
- `Wallet-Diary-v1.5.0.aab`: Google Play Console 제출용 서명 Android App Bundle
- 패키지 ID: `com.seunghyeonkim.walletdiary`
- 버전: `1.5.0` (version code 108)
- 최소 Android: 7.0 / API 24, target/compile SDK: 36

## 이번 업데이트

- 동행에게 보내기는 BIN/JSON 대신 `.pdf`, `application/pdf`와 읽기 권한을 공유 앱에 전달합니다.
- PDF 저장은 공유창 대신 Android 파일 저장창을 열어 선택한 휴대폰 위치에 씁니다. 취소하면 저장 성공으로 표시하지 않습니다.
- 일반 가계부도 전체 기간 내역과 카테고리 합계를 PDF로 저장합니다.
- 앱에서 만든 PDF는 원본 데이터를 포함하여 참가자·결제자·분담 금액을 정확히 다시 가져와 합칠 수 있습니다.
- 상단 가져오기는 PDF·엑셀·CSV/TSV·OFX/QIF·JSON·텍스트·HTML·DOCX/ODT와 Android 이미지/스캔 PDF를 읽습니다. 파일 선택에 확장자 제한을 두지 않습니다.
- 날짜·사용처·금액·화폐·카테고리 수정, 기간·건수·합계 확인 후 등록합니다. 기존 기록·잔액·입금·실패·취소 제외, 명확한 같은 파일 환불 차감, 열 매핑과 인코딩 선택을 지원합니다.
- 한국어·영어·프랑스어 및 기존 자동기록·생활→여행 이동·편집·통계·월 한도를 유지합니다.

## 설정과 확인

받은 PDF를 휴대폰에 저장한 뒤 상단 가져오기에서 선택하세요. 앱 원본 PDF는 여행 합치기 화면이 열립니다. 외부 은행 파일은 내용을 확인한 뒤 일반 가계부 또는 여행에 등록하세요. 화폐를 임의로 환산하지 않습니다.

모든 임의 파일·은행 서식·암호화 문서를 인식하는 것은 아닙니다. 이미지·스캔 결과는 원본과 확인하세요. 기기 내 문자 인식은 라틴·한국어·중국어·일본어·데바나가리를 지원합니다. 읽기 제한은 40 MB/외부 PDF 100페이지/20,000행이며 가계부 저장은 5,000건입니다. 이미 등록한 결제의 나중 환불은 기존 결제를 편집하세요.

국가·패키지 목록으로 은행을 제한하지 않지만 모든 은행·언어·알림 형식의 인식을 보장하지 않습니다. 삭제된 알림은 복원할 수 없고, 알림이 전혀 없는 거래는 읽지 않습니다. 실계좌 자동 동기화는 공식 Open Banking 공급자·백엔드·은행 인증 및 동의 연결이 아직 필요합니다. 은행 앱의 비공개 화면이나 저장소를 읽지 않습니다.

## 설치와 보관

기존 앱과 같은 서명 키를 사용합니다. 앱을 삭제하지 말고 APK를 열어 업데이트하세요. 중요한 가계부는 업데이트 전에 PDF로 백업하세요. 실제 카카오톡·WhatsApp 수신 및 모든 갤럭시 모델에서 실기기 검증을 완료한 것은 아닙니다. AAB 서명이 Play Console 심사 승인을 의미하지는 않습니다.

SHA-256 파일 해시는 `SHA256SUMS.txt`에 있습니다. `wallet-diary-upload.jks`, `signing.properties`, `SIGNING-CREDENTIALS.txt`는 민감한 서명 자료라 Git에 포함되지 않습니다. 안전한 별도 위치에 백업하세요.

서명된 IPA 생성에는 macOS/Xcode와 Apple Developer 배포 인증서·프로비저닝 프로파일이 필요합니다.
