# 지갑의 일기 v1.3.0

- `Wallet-Diary-v1.3.0.apk`: Android 기기에 직접 설치하는 서명 APK
- `Wallet-Diary-v1.3.0.aab`: Google Play Console 제출용 서명 Android App Bundle
- 패키지 ID: `com.seunghyeonkim.walletdiary`
- 버전: `1.3.0` (version code 104)
- 최소 Android: 7.0 / API 24
- target/compile SDK: 36

이번 버전은 특정 카드사 목록 제한 없이 모든 Android 앱에서 지원되는 결제 형식 알림을 기기 안에서 감지하도록 시도합니다. 은행·언어·알림 형식에 따라 일부 거래가 누락될 수 있습니다. 실패·입금·이체·부분 환불은 제외하며, 확정된 결제 취소·전액 환불은 정확히 일치하는 자동 지출만 제거하고 모호한 경우에는 검토함에 남깁니다. 자동등록 내역 편집과 월 소비 한도 알림도 그대로 지원합니다.

사용 방법은 `일반 가계부 → 카드 자동기록 → 앱 제한 없이 결제 알림 감지 → Android 알림 접근 허용` 순서입니다. 새 앱의 첫 결제 후보에서는 해당 앱이 은행·카드사의 공식 앱이고 중계 앱이 아님을 확인한 뒤 `이 앱을 신뢰하고 등록`과 `지출로 기록`을 각각 눌러야 하며, 이후 신뢰도가 높은 결제 알림부터 자동 기록됩니다.

알림 원문은 저장하거나 외부로 전송하지 않습니다. 인식된 사용처 문자열에서는 알려진 OTP·카드/계좌번호·이메일·전화번호·거래 참조번호 형식을 제거합니다. 앱이나 은행이 결제 금액·사용처를 알림에 표시하지 않거나 지원되지 않는 형식을 사용하면 자동 인식할 수 없습니다.

문자·메일·브라우저·메신저처럼 여러 발신자를 대신해 알림을 보여주는 앱은 다른 발신자의 위조 알림을 자동 지출로 오인하지 않도록 매 건 확인 후 기록합니다. 결제 취소도 같은 안정 이벤트로 확인된 경우에만 자동 지출을 제거하고, 사용처·금액만 일치하는 경우에는 사용자가 검토하도록 남깁니다.

APK는 v2 서명 검증을, AAB는 JAR 서명 검증을 통과했습니다. SHA-256 파일 해시는 `SHA256SUMS.txt`에 있습니다.

`wallet-diary-upload.jks`, `signing.properties`, `SIGNING-CREDENTIALS.txt`는 민감한 서명 자료라 Git에 포함되지 않습니다. 세 파일을 별도로 안전하게 백업하세요.

iOS 프로젝트는 준비되어 있지만 서명된 IPA는 Windows에서 생성할 수 없습니다. macOS/Xcode와 Apple Developer 배포 인증서·프로비저닝 프로파일을 연결한 뒤 archive/export해야 합니다.
