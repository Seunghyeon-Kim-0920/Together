# 지갑의 일기 v1.4.1

- `Wallet-Diary-v1.4.1.apk`: Android 기기에 직접 설치하는 서명 APK
- `Wallet-Diary-v1.4.1.aab`: Google Play Console 제출용 서명 Android App Bundle
- 패키지 ID: `com.seunghyeonkim.walletdiary`
- 버전: `1.4.1` (version code 107)
- 최소 Android: 7.0 / API 24, target/compile SDK: 36

## 이번 업데이트

- Swile 한정이 아닌 한국·해외의 임의 앱에서 결제 알림을 발견할 수 있도록 미등록 앱의 검토 흐름을 확장했습니다.
- 사용처가 없는 결제는 버리지 않고 사용자가 사용처를 입력한 뒤 확인하도록 합니다. 처음 보는 앱은 자동으로 신뢰하지 않습니다.
- Euro/Euros/유로, 원, 円 표기와 여러 알림 구조를 지원합니다. 결제 금액과 잔액을 구분하고 입금·실패·예정 거래를 제외합니다.
- 현재 가계부와 화폐가 다른 내역도 숨기지 않고, 같은 화폐의 일반 가계부를 열거나 만들도록 안내합니다. 임의 환산하지 않습니다.
- `현재 알림 다시 확인`으로 알림창에 남은 알림을 재검사합니다. 이미 확인한 동일 알림은 다시 추가하지 않으며 변경된 취소 알림은 따로 검토합니다.
- 알림 접근 권한과 실제 감지 서비스 연결 상태를 구분해 안내합니다. 앱을 보고 있는 동안에는 확인 목록을 주기적으로 갱신합니다.
- 기존 생활→여행 이동, 여행 파일 공유·중복 방지 합치기, 편집, 통계와 월 한도 기능은 유지합니다.

## 설정과 확인

일반 가계부의 `알림 기반 결제·이체 자동기록` 설정에서 Android 알림 접근을 허용하고 `앱 제한 없이 결제·이체 알림 감지`를 켜세요. 새 앱의 항목은 실제 은행·카드사의 공식 앱인지 확인해 신뢰 앱으로 등록하고 첫 결제를 직접 확인합니다. 사용처가 없으면 먼저 입력하세요. 이미 알림창에 있는 항목은 `현재 알림 다시 확인`을 누릅니다.

국가·패키지 목록으로 은행을 제한하지 않지만 모든 은행·언어·알림 형식의 인식을 보장하지 않습니다. 삭제된 알림은 복원할 수 없고, 알림이 전혀 없는 거래는 읽지 않습니다. 실계좌 자동 동기화는 공식 Open Banking 공급자·백엔드·은행 인증 및 동의 연결이 아직 필요합니다. 은행 앱의 비공개 화면이나 저장소를 읽지 않습니다.

## 설치와 보관

기존 앱과 같은 서명 키를 사용합니다. 앱을 삭제하지 말고 APK를 열어 업데이트하세요. 중요한 가계부는 업데이트 전에 파일로 백업하세요. 실제 Swile 알림 전문 및 모든 갤럭시 모델에서 실기기 검증을 완료한 것은 아닙니다.

SHA-256 파일 해시는 `SHA256SUMS.txt`에 있습니다. `wallet-diary-upload.jks`, `signing.properties`, `SIGNING-CREDENTIALS.txt`는 민감한 서명 자료라 Git에 포함되지 않습니다. 안전한 별도 위치에 백업하세요.

서명된 IPA 생성에는 macOS/Xcode와 Apple Developer 배포 인증서·프로비저닝 프로파일이 필요합니다.
